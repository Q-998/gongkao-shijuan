## 怎么用

1. **在线看**：点进任意目录，再点 PDF 文件，GitHub 会直接在线预览。
2. **下载单份**：在文件页面点右上角的下载按钮即可。
3. **整包克隆**（约 1.9 GB，建议网络良好时进行）：

   ```bash
   git clone https://github.com/Q-998/gongkao-shijuan.git
   ```

4. **打印**：多份试卷是扫描版或图片版，打印时选「适应页面」。

## 说明

- **年份口径**：以试卷名称中的年份为准。国考按**举办年份**命名，
  2023 年底举行的国考其试卷名为「2024 年」。
- **联考**：多省同日联考，个别省份自主命题（如江西、湖南）；
  部分省份不公布题目，可参考其他省份的联考卷。
- **试卷形态**：多数为排版版 PDF，部分年份（如 2022 年部分省份、
  2023/2024 年国考）为扫描版或纯图版，也有几份标注「网友回忆版」，
  个别题目可能与原卷有出入。
- **北京市考**的答案附在试卷末尾，没有单独答案目录。
- **另有两份非 PDF 文件**：`省考以及市考/四川省考/答案/2022上半年四川省考答案（行测）.docx`；
  `省考以及市考/广州市考/试卷/2019年广州未考.txt` 说明广州当年未举行考试。
