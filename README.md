## 怎么用

1. **在线阅读**：直接从上面的导航进入年份目录，点开任意 `.md` 文件即可在 GitHub 上看题、答案与解析。
2. **克隆到本地**：

   ```bash
   git clone https://github.com/Q-998/gongkao-shijuan.git
   ```

   图片是相对路径，本地用 Obsidian / VS Code / Typora 打开文件夹即可正常显示。
3. **离线刷题**：整套仓库约 280 MB，克隆一次即可永久离线使用。

## 说明

- **年份**：以试卷名称中的考试年度为准，2016–2026 全覆盖。
- **模块**：政治理论、常识判断、言语理解与表达、数量关系、判断推理、资料分析。
  515 套中有 395 套齐备 6 个模块；其余 120 套因原题库缺少个别模块而不完整，卷首的模块目录会如实反映。
- **联考的归属**：原题库只在 2016–2019 年的试卷名中显式标注「联考」，
  2020 年之后的多省联考卷按省份命名，因此归在「省考」下，查看时请注意。
- **缺失图片**：全库 39,461 张图片中有 **2 张**在原始题库即已缺失
  （`formula-4daf9a3762c10376.png`、`formula-2c7a9ff6774e3af2.png`），不影响题目与解析阅读。
