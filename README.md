## 四、检索技巧与注意事项

**继续深挖可以用这些 GitHub 高级检索式：**

- `公务员 in:name,description`、`行测 in:name,description`、`公考 in:name,description`
- `topic:gongkao`、`topic:civil-service-exam` 按话题标签找
- 加 `sort:stars`，或直接在仓库搜索页选「Most stars」排序
- 代码级搜索：`行测 filename:README.md`、`申论 extension:md`

**几点提醒：**

- **版权**：真题版权归命题机构所有，这些仓库多为个人整理分享，建议仅作个人学习使用，勿商用或二次分发。
- **时效**：星标数与内容更新时间为 2026-10-03 检索快照，后续可能变化；试卷年份以各仓库 README 为准。
- **网盘类仓库**：分享链接易失效，且内容未经审核，下载前请自行判断安全性。
- **优先顺序建议**：先看第一节的 `ERRRC/xingcezhenti`（题量最大、解析最全），再用 `Yaoyuan-Zhang319` 的打包下载补早年试卷。
